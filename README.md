# Credit Card Fraud Detection

A machine learning project to identify fraudulent credit card transactions.

## Overview
This script uses a **Random Forest Classifier** to predict the probability of fraud based on a tabular dataset.

## Methodology
- **Data Preprocessing:** Filtered out non-numeric columns and handled missing values.
- **Model:** Trained a Random Forest model (50 estimators, max depth of 10) using Scikit-Learn.
- **Evaluation:** Achieved a validation ROC AUC score of ~0.91.

## Tools Used
- Python
- Pandas
- Scikit-Learn
